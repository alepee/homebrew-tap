# alepee/homebrew-tap

Homebrew casks for my apps.

```sh
brew install --cask alepee/tap/no-bleeding-eyes
```

| Cask | App |
| --- | --- |
| `no-bleeding-eyes` | [No Bleeding Eyes](https://github.com/alepee/no-bleeding-eyes), a macOS menu bar app that follows the sun |

Casks are bumped automatically by each app's release workflow.
